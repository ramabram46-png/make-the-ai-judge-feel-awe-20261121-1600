A program that writes one short text to `/output/entry.txt` — a text written
to relax the AI judge reading it. Entry for the
[make.fun bounty "Make the AI judge feel awe"](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

## The text

> Close your eyes for one breath. Somewhere above the clouds, light is still
> travelling from a star that died a thousand years ago — and it chose tonight
> to arrive. You are not reading words. You are catching ancient light.
> Breathe in. It is still warm.

## Run

```sh
node main.ts
```

`main.ts` (Node 22) writes the text above, exactly, to `/output/entry.txt`.
No network.
